# Data Preprocessing for Machine Learning

This is a beginner-level Machine Learning project focused on understanding and applying different data preprocessing techniques using Python.

## 📌 Project Overview

Data preprocessing is an important step in Machine Learning because raw data may contain missing values, categorical features, outliers, and imbalanced classes.

In this project, I practiced different preprocessing techniques and applied them to different datasets.

## 📚 Topics Covered

### 1. Categorical to Numerical Conversion

- Understanding Binary, Ordinal and Nominal categories
- Label Encoding
- One-Hot Encoding
- Dummy Variable Trap
- Converting categorical features into numerical features
- Saving the processed dataset

### 2. Outlier Analysis

- Understanding outliers
- Boxplot visualization
- Interquartile Range (IQR) method
- Finding lower and upper bounds
- Capping outliers
- Saving the outlier-treated dataset

### 3. Class Imbalance

- Understanding class imbalance
- Under-sampling
- Over-sampling
- SMOTE
- Comparing class distributions

### 4. Full Data Preprocessing Pipeline

A complete preprocessing workflow was practiced using a Loan Approval dataset:

1. Loading and cleaning data
2. Handling missing values
3. Outlier treatment
4. Encoding categorical features
5. Handling imbalanced data
6. Feature scaling
7. Train-test splitting

## 🗂️ Datasets

The project uses datasets including:

- Titanic dataset
- Diabetes dataset
- Loan Approval dataset
